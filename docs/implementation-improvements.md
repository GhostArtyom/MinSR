# MinSR 实现改进

## 数值一致性验证

**固定输入对照在已测条件下通过；不能保证逐位相同，也不能保证训练到最后得到完全相同的权重和能量。** 优化没有改变 Heisenberg 算符、Metropolis 提议和接受规则或 MinSR 更新公式，也没有减少样本数、采样步数或降低计算精度。卷积、求和和矩阵乘法的浮点运算顺序可能不同。即使种子相同，微小的振幅差异也可能改变一次接受判定，让后续采样和训练轨迹分开。

- **固定输入。** JAX CPU、Torch CPU 参考对照和 Torch CUDA 检查均已通过。对照覆盖波函数、逐样本局域能量、Jacobian、Gram 矩阵和 MinSR 参数更新。接近波函数零点时，局域能量里的振幅比会放大误差：`3064` 的一次固定构型检查中，cuDNN 与周期卷积的逐样本局域能量最大相对差为 1.27%；换用一批从近 Néel 构型热化的样本后，最大相对差为 $8.51\times10^{-5}$。这两个数只对应各自的样本。
- **单独切换采样图。** 固定种子的测试核对了链构型、随机数状态、振幅和幅值上限。在归档 `params_2000.eqx` 的 1000 样本短测中，开关前后的逐步总能量最大绝对差约为 $2.27\times10^{-5}$。这不是所有优化的误差上界。
- **完整训练。** RTX 4070 Ti 上的 PyTorch 通用版和优化版都完成了 `2000 + 1000 + 100` 流水线。两段训练末 200 步和最终测量的总能量及中心方差均落在 JAX 归档设定的工程容差内。[验收结果](pytorch-migration-plan.md#完整验收结果)

## JAX 与 PyTorch 耗时对比

RTX 5060 Ti，10×10 周期方格，$J_1=1$、$J_2=0.5$，16 层、16 通道、3×3 卷积，1000 个样本。训练每步 200 次交换提议；固定权重测量每轮 1000 次。Torch 测试使用 `2.10.0+cu128`。下表用稳态中位数，不计热化和首次编译，训练另外排除绘图和存盘。

| 阶段 | 原版 JAX | 优化版 Torch |
| --- | ---: | ---: |
| 普通训练 | 2.44 秒/步 | 0.981 秒/步 |
| 对称性训练 | 30.20 秒/步 | 9.436 秒/步 |
| 固定权重测量 | 83.28 秒/轮 | 21.18 秒/轮 |

JAX 来自启用设备端局域能量之前的完整归档：[普通训练](../runs/j1j2_square_10x10_J1-1_J2-0.5/20261119_030050/training.log)、[对称性训练](../runs/j1j2_square_10x10_J1-1_J2-0.5/20261119_051106/training_symm.log)、[固定权重测量](../runs/j1j2_square_10x10_J1-1_J2-0.5/20261119_150209/measurement.log)。各阶段去掉前 10 步或轮；训练排除每 10 步和最后一步，避开归档中的绘图和存盘。

Torch 普通训练取预热 2 步后的 4 步，对称性训练取预热 1 步后的 3 步，测量取第 2–4 轮。对称性训练和测量都用对应 JAX 归档中的同一份起始权重，采样独立。JAX 是长跑日志，Torch 是短测；表中比较的是单步成本，不能据此推算达到同一能量所需的时间。Torch 对称性训练和测量的计时记录在本地 `runs/torch-perf/docs-speed-comparison/`。

另有两组只比较 Torch 的对照：普通训练用相同随机初始化，提交 `e2ebdbe` 对当前优化版为 **2.256 → 0.981 秒/步**；归档 `20261119_054229/params_2000.eqx` 的对称性训练只切换采样图，为 **9.780 → 9.504 秒/步**。后一组开启采样图后，局域能量仍占约 5.96 秒/步，约为整步的 63%。原始记录在本地 `runs/torch-perf/cache-and-adjoint/`。

## PyTorch 实现优化

| 环节 | 当前实现 |
| --- | --- |
| 交换采样 | 用 CUDA Graph 重放交换提议。对称性采样跳过同向自旋造成的自转移，不为它们重复计算振幅；有效提议数量留在设备上，仍为每个有效构型计算完整对称轨道。不支持重放时回退到即时压缩。 |
| 局域能量 | 合并两种交换方向，压缩有效连接后分批在设备上计算波函数并按样本累加。支持的对称性路径对足够长的连接列表重放整批前向；仍有动态压缩同步。 |
| 周期卷积 | 直接按周期坐标取值，避免单独生成周期填充张量。支持的层把 ReLU、残差加法或末端归约合入 CUDA 内核，卷积仍用 IEEE FP32。 |
| MinSR | 用批量反传计算逐样本导数，投影路径按完整对称轨道归约。单进程实值 CUDA 路径在 320 MiB 内缓存全部或部分导数，只重算未缓存的块；缓存原生 FP32 导数时仍用 FP64 构造 Gram 矩阵和计算更新。符合条件的 Gram 只计算一个三角再补齐，求解器不变。 |
| 绘图 | 前 100 步每 10 步画一次，此后每 100 步画一次，最后一步也出图。只改变输出频率。 |

直接周期卷积用于满足条件的二维实值 `ResSum`，需要 Triton 和 C 编译器。在 `sm_120` 上，对称性路径支持 `1616`、`1632`、`3064` 和通过 `ResSum` 参数校验的非预设尺寸，核按晶格、通道数和卷积核尺寸特化。普通训练支持 8–64 通道的 2×2 卷积，以及通道数为 16 的倍数且核宽至少为 3 的配置。相关开关见 [运行配置](pytorch-migration-plan.md#cuda-开关)。

`nsamples` 是采样链数。`max_parallel` 限制一次网络前向的输入数；对称性训练和测量的 CUDA 推理再受 `projected_forward_batch=1024` 限制，实际取两者的较小值。这里数的是展开后的对称轨道成员，16 个成员时最多处理 64 个完整构型。调这个值不会改变 `nsamples` 或直接改变 MinSR 的求导分块；批次更大也不一定更快。

### CUDA 设备适配与性能

RTX 5060 Ti（`sm_120`）和 RTX 4070 Ti（`sm_89`）共用上述内核。4070 Ti 的路径按下表启用，适用条件为 10×10 周期方格、16 层、3×3 卷积、`use_sinh=True`、1000 样本、`max_parallel=32768`、FP32 参数和 FP64 状态。对称性训练和测量另要求 `projected_forward_batch=1024`。其余配置沿用通用路径。

| 4070 Ti 配置 | 启用的优化 | 沿用的通用路径 |
| --- | --- | --- |
| 16 通道普通训练 | 周期前向、FP64 cuBLAS 下三角 Gram | 批量 `unfold` 权重梯度 |
| 16 通道对称性训练和测量 | 周期前向、压缩交换和局域能量 CUDA Graph | 对称性训练采用通用自动微分和完整 Gram |
| 32 通道普通训练 | 周期卷积权重梯度 | 完整 Gram，前向沿用 cuDNN |

4070 Ti 的 16 通道短测以同卡 `df1dbfc` 为基线，复用相同初始化或归档权重。普通训练、对称性训练和测量的稳态中位数分别为 **1.502 → 0.851 秒/步**、**17.383 → 8.169 秒/步**、**35.664 → 13.923 秒/轮**。局域能量 Graph 在测量的同进程配对中将整轮耗时从 14.534 降至 13.923 秒，复用捕获内存池后保留显存稳定在 210 MiB。[4070 Ti 短测记录](../runs/torch-perf/sm89/)

### MinSR 快路径对照

两张卡的 16 通道配置都可缓存全部导数。下表每行比较同一张卡的开关，单位为秒/步。5060 Ti 采用固定样本和局域能量的 6 组配对；4070 Ti 的 Gram 对照取普通训练短测，32 通道权重梯度对照采用同进程的 4 组配对。

| 设备 | 优化 | 通道 | 普通训练 | 对称性训练 |
| --- | --- | ---: | ---: | ---: |
| RTX 5060 Ti | cuBLAS 下三角 Gram（对比分块 GEMM） | 16 | 1.059 → 1.018 | 9.460 → 9.413 |
| RTX 5060 Ti | cuBLAS 下三角 Gram（对比分块 GEMM） | 32 | 2.624 → 2.440 | 22.361 → 22.160 |
| RTX 5060 Ti | 部分导数缓存（cuBLAS 路径相同） | 32 | 2.440 → 2.405 | 22.160 → 21.906 |
| RTX 4070 Ti | cuBLAS 下三角 Gram（对比完整 GEMM，均开启周期前向） | 16 | 0.810 → 0.799 | — |
| RTX 4070 Ti | 周期卷积权重梯度 | 32 | 4.206 → 4.040 | — |

5060 Ti 的更新向量在 `rtol=1e-10, atol=1e-11` 下通过，峰值分配未见实质增加。4070 Ti 的 16 通道周期权重梯度和对称性训练的下三角 Gram 均超出各自更新容差，沿用通用路径。32 通道普通训练单开周期权重梯度可稳定缩短整步，叠加下三角 Gram 的整步收益未能复现。5060 Ti 的配对计时原目录为 `runs/torch-perf/gram-cache-review/`，4070 Ti 的 CUDA 检查、分项计时和显存记录见 [短测目录](../runs/torch-perf/sm89/)。

## JAX：设备端局域能量

[`Heisenberg(device_local=True)`](../quantax/operator/common_operators.py) 在设备上枚举有效自旋交换、分批计算波函数，并按样本累加贡献，避免每步经 CPU 和 QuSpin 展开连接构型。它保留 Pauli 归一化、`msr=True` 只翻转第一近邻的横向项，以及原来的对称投影。三个 JAX 示例默认启用；需要单设备 `Variational` 自旋态和 `max_parallel`，否则走通用 QuSpin 路径。精确对角化接口不受影响。

RTX 4070 Ti 上，10×10 方格、16 层 32 通道 3×3 网络、1000 个样本的 40 步普通训练，对比通用路径和设备路径，第 11–40 步平均耗时为 **2.709 → 2.472 秒/步**。两条路径的 40 步能量和方差在日志精度内一致。另一个固定构型对照中，同一批 1000 个样本的投影局域能量最大绝对差约为 $7\times10^{-10}$。

`MAX_PARALLEL` 不限制 MinSR 反传的全部显存。若 CUDA 对称性训练抛出 `RESOURCE_EXHAUSTED`，先验证一次完整更新再重跑；32 通道配置曾用 `XLA_PYTHON_CLIENT_PREALLOCATE=true` 和 `XLA_PYTHON_CLIENT_MEM_FRACTION=0.8` 通过验证。若日志注明 `this is not a failure` 且训练仍在推进，则只是 XLA 未能为某个候选算法分配显存。
