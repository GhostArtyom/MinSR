# MinSR 中文导读

这个仓库用神经网络表示量子自旋系统的波函数，通过变分蒙特卡洛和随机重构优化网络参数，求取基态或指定对称性扇区中的低能态。仓库包含 MinSR 优化器、配套的 Quantax 源码、5 个入门教程，以及训练脚本、已训练权重和论文图表数据。

| 文档 | 内容 |
| --- | --- |
| [项目分析](project-overview.md) | 项目解决的问题、计算流程、MinSR 原理、代码结构及训练示例 |
| [教程导读](tutorial-guide.md) | 5 个 Notebook 分别教什么、关键代码的含义、阅读顺序和运行注意事项 |

建议先读项目分析中的“计算怎样完成”，再按顺序阅读教程。准备环境时以仓库根目录的 [README](../README.md) 和 [pyproject.toml](../pyproject.toml) 为准。

这些说明依据当前仓库的源码和 Notebook 单元内容整理。文档中的教程参数是代码配置；没有重新运行完整训练，也没有据此给出新的性能或收敛结论。
