# 5 个教程分别教什么

这组 Notebook 按“建立小系统基准、使用卷积网络、学习符号、处理复振幅、选择激发态扇区”的顺序展开。教程 2、3、5 使用 4×4 方格，教程 4 使用 6×6 三角格，教程 1 使用 12 个格点的链；未另行指定时采用周期边界。

5 个教程都使用 `TDVP` 做虚时间优化；第 1 个还展示 `TDVP_exact`。想看 `MinSR` 类如何训练较深网络，应在读完教程后查看 [examples/train.py](../examples/train.py)。算法和代码之间的关系见[项目分析](project-overview.md)。

## 1. Ising：从精确解理解一次变分训练

[第 1 个教程](../tutorials/1-Ising.ipynb) 先设置随机种子 2347、默认计算类型 `float64` 和网络参数类型 `float32`，然后创建 `Chain(12)`。这一步介绍了 Quantax 的使用约定：晶格是隐式传给后续对象的全局常量，必须先创建。

随后用两种写法构造相同的横场 Ising 哈密顿量：调用 `qtx.operator.Ising(h=1)`，或用 `sigma_z`、`sigma_x` 手工求和。周期链上的表达式为：

$$
H=-\sum_{i=0}^{L-1}\sigma_i^z\sigma_{i+1}^z-h\sum_{i=0}^{L-1}\sigma_i^x,\qquad \sigma_L^z=\sigma_0^z.
$$

教程用 `Trans1D() + SpinInverse() + Flip()` 组合零动量、自旋反演偶性和反射偶性，在该扇区内求最低的 3 个本征态。它将最低态的波函数包装成 `DenseState`，用 `dense @ H @ dense` 检查能量与对角化结果一致，建立后续训练的参照。

变分网络是 `RBM_Dense(features=4*L)`，即 48 个隐藏特征。教程先用 `TDVP_exact` 在完整的对称性基底上优化 100 次，步长系数为 0.01，再将训练后的变分态转成归一化的稠密态，直接计算能量。

最后重新初始化 RBM，使用 `LocalFlip(state, nsamples=1000)` 和随机 `TDVP` 优化 100 次，步长仍为 0.01。两段训练使用不同的初始网络，适合比较精确计算和采样估计的流程；不能把两条曲线当作相同初始化下的严格性能对照。

读完这一节，应能说明 `DenseState` 与 `Variational` 的区别，知道 `H.diagonalize`、`state.todense` 和 `TDVP_exact` 为何适合小系统，并能写出“采样、求更新方向、更新参数、记录能量”的循环。

## 2. Heisenberg：卷积网络和波函数对称化

[第 2 个教程](../tutorials/2-Heisenberg.ipynb) 在 4×4 方格上定义 `Heisenberg(msr=True)`，最近邻耦合默认为 1。`msr=True` 使用 Marshall 符号变换后的哈密顿量表示；此处网络采用默认的实数指数输出。

网络是 `ResSum(4, 8, 4)`：4 个卷积层、8 个通道、4×4 卷积核。与 RBM 相比，卷积网络利用晶格上的平移结构。周期卷积和末端空间求和已编码零动量平移对称性，因此训练时没有再显式加入 `Trans2D()`。

初始变分态只指定 `TotalSz()`，即零总磁化；采样器改成 `NeighborExchange(state, 1000)`。交换两个格点的自旋可以保持磁化不变，适合这个扇区。第一阶段使用 `TDVP` 训练 200 次，步长系数为 0.001，同时记录能量和能量方差。

第二阶段把训练所得波函数投影到 `TotalSz() + SpinInverse() + C4v()`，再训练 200 次。空间对称化的含义是：对一个构型施加群变换，计算各个变换后的网络输出，再按目标表示的特征标加权平均。教程给出的形式为：

$$
\psi_{\mathrm{symm}}(s)=\frac{1}{|G|}\sum_{g\in G}\omega_g^{-1}\psi(T_gs).
$$

这里 $T_g$ 表示群作用，$\omega_g$ 是目标表示的特征标。教程展示了 3 种构造对称态的方法：用训练后的 `state.ansatz` 新建 `Variational`；先保存 `.eqx` 权重再载入带对称性的同结构网络；直接调用 `symm(state)`。第二种方法把权重保存在 `/tmp/Heisenberg_params.eqx`。

末尾精确对角化时，教程显式使用 `full_symm = symm + Trans2D()`，让基准基底也包含网络中已编码的平移约束。本节要理解的是：网络结构能编码部分对称性，外部投影能进一步限制搜索空间；投影后仍可继续优化权重。

## 3. J1-J2：让实网络学习正负号

[第 3 个教程](../tutorials/3-J1J2.ipynb) 保留上一节的方格、网络规模和两阶段训练结构，把哈密顿量改为：

```python
H = qtx.operator.Heisenberg(J=[1, 0.5], n_neighbor=[1, 2], msr=True)
net = qtx.nn.ResSum(4, 8, 4, use_sinh=True)
```

`J` 与 `n_neighbor` 按位置对应：第一近邻耦合为 1，第二近邻耦合为 0.5。加入第二近邻项后，网络需要表达额外的符号结构；这里启用 `use_sinh=True`，让输出可以取正值或负值。

从源码看，末端激活包含整体尺度 $e^{\theta_0}$，形式为 $e^{\theta_0}[\sinh(x)+1]$。符号学习依赖激活允许变号这一性质。默认的实数指数输出始终为正，无法单独表达这类符号变化。

采样器也使用 `n_neighbor=[1, 2]`，允许在两类键上交换自旋。哈密顿量的近邻设置决定物理模型，采样器的近邻设置决定提出哪些构型变化，两者是不同的参数用途。

教程先在 `TotalSz()` 扇区训练，再加入 `SpinInverse()` 和 `C4v()` 继续训练，最后加上 `Trans2D()` 做精确对角化。本节适合与教程 2 对照阅读：训练循环基本相同，关键变化是第二近邻耦合和允许变号的网络输出。

## 4. Triangular：复振幅和相位先验

[第 4 个教程](../tutorials/4-Triangular.ipynb) 将晶格改为 `Triangular(6)`，共 36 个格点，耦合为 $J_1=1$、$J_2=0.125$。它不启用 `msr`，并在构造晶格和网络之前调用：

```python
qtx.set_default_dtype(jnp.complex128)
```

网络参数仍使用默认的 `float32`。`ResSum(4, 8, 3)` 在末端将实通道配成复数，再使用复指数输出，因此可以同时表达振幅和相位。这里学习的是“实参数、复输出”的状态，并没有把全部卷积参数改成复数。

教程还创建 `qtx.nn.Neel120()`，作为 120° Néel 结构的相位先验，将它与变分网络相乘后施加总磁化约束：

```python
sign_net = qtx.nn.Neel120()
state = qtx.state.Variational(net, max_parallel=32768)
state = TotalSz()(state * sign_net)
```

`Neel120()` 的默认输出类型是相位。当前组合实现会把这个外部网络包装成与变分参数无关的函数，因此在这一写法中，先验保持固定，优化的是 `ResSum` 的参数。它为变分态提供相位结构，训练结果仍需通过能量和方差判断。

第一阶段只固定总磁化，第二阶段加入 `SpinInverse()` 和三角格点群 `D6()`。两阶段各训练 200 次，步长系数均为 0.001；每 10 次刷新一次能量和方差图。与前几个小方格教程相比，这一节没有提供精确对角化基准单元。

读完这一节，应能区分“复数计算类型”“复数网络参数”和“复数波函数输出”，并能沿着 `state * sign_net` 追踪网络输出如何与固定相位函数组合。

## 5. ExcitedState：用对称性选出低能激发态

[第 5 个教程](../tutorials/5-ExcitedState.ipynb) 回到 4×4 方格的 $J_1=1$、$J_2=0.5$ 模型，仍使用 `use_sinh=True`。它把非零平移动量直接传给 CNN 的末端求和：

```python
trans_symm = Trans2D(sector=(2, 2))
net = qtx.nn.ResSum(4, 8, 4, use_sinh=True, trans_symm=trans_symm)
```

`sector` 是离散动量扇区编号。对于长度为 4 的两个周期方向，编号 `(2, 2)` 对应 $(\pi,\pi)$。网络末端使用相应平移特征标加权，而不是默认的均匀空间求和。

第一阶段先在 `TotalSz()` 约束下训练 200 次，第二阶段增加：

```python
symm = TotalSz() + SpinInverse(-1) + C4v()
symm_state = symm(state)
```

`SpinInverse(-1)` 要求 $\psi(-s)=-\psi(s)$。动量和反演奇偶性共同限制了搜索空间，优化在目标扇区内寻找低能态。教程没有添加与已知基态正交的惩罚项，也没有逐个求出整个系统的激发谱；结果应理解为所选扇区中的低能态。

末尾的精确对角化代码是 `H.diagonalize(symm)`。这里的 `symm` 含总磁化、自旋反演和点群约束，未显式包含 `trans_symm`；CNN 中的动量设置不会自动传入这次对角化。若要严格对照相同的对称性扇区，可另行使用：

```python
E, wf = H.diagonalize(symm + trans_symm)
```

这是根据当前代码给出的比较方式，原 Notebook 保持不变。仅凭原末尾单元，不能认定精确基准已显式固定到与 CNN 相同的动量。

## 阅读和运行建议

第一次接触项目时按 1 → 2 → 3 → 4 → 5 阅读。教程 1 建立精确解与采样优化之间的联系；教程 2、3 适合对照网络结构和符号表达；教程 4 介绍复输出和先验；教程 5 则要求理解对称性扇区的含义。若目标是复现仓库中的 10×10 方格训练，读完教程 3 后可以转向 `train.py`、`train_symm.py` 和 `measure.py`。

运行前按根目录的 [README](../README.md#installation) 配好环境，在 Notebook 编辑器中选择项目 `.venv/bin/python`。每个教程使用独立内核；切换教程前重启内核，避免全局晶格、数据类型和对称性缓存相互影响。

教程 2-5 把 `max_parallel` 设为 32768。这是每台设备的前向批量上限，对称化后一个原始构型会产生多个变换输入；显存或内存不足时可调低该值。优化器的导数矩阵及样本空间矩阵也占内存，必要时还需降低样本数或网络规模。多设备采样要求 `nsamples` 能被本地设备数整除。

计时单元在循环前后调用 `jax.block_until_ready(...)`，等待设备计算完成。首次调用还可能包含 JIT 编译开销，Notebook 打印的整段优化时间不能直接视为排除编译后的单步耗时。

能量下降和方差减小可以帮助观察训练，但完整判断还需要独立测量、采样质量及小系统精确基准。教程展示的是这些操作和接口的用法，固定的迭代次数不构成收敛保证。
